# Security policy

Mac Tidy is a local maintenance utility whose main security boundary is
preventing unintended file deletion or system changes.

Report vulnerabilities through GitHub's private vulnerability reporting page
for this repository. Include the affected version, exact command or UI flow,
expected boundary, observed behavior, and a reproduction using disposable
data. Do not publish destructive proofs or private local paths in a public
issue.

The current `main` branch and latest tagged release receive security fixes.
Ordinary bugs and feature requests may use public GitHub issues.

The bundled engine retains Mole's own security documentation in
`Vendor/Mole/SECURITY.md` and `Vendor/Mole/SECURITY_AUDIT.md`.
